# 구조 단계 점검표 (S 계열)

문장 아래, 글의 뼈대에서 드러나는 AI 티를 본다. 출처는 [sepia](https://github.com/Nanako0129/sepia)(MIT)의 `professional-pass.md`(비소설 점검 10개)와 `discourse-pass.md`(담화 흐름)이고, 한국어 업무 문서에 맞게 옮겼다.

> **근거의 무게**: sepia가 기댄 연구(StoryScope, QUDsim, SLOPSHAPE)는 영어 코퍼스다. 아래 S 항목은 **한국어 실측 전**이다. 판별력이 확인된 humanize-korean 패턴과 같은 무게로 다루지 않는다. 한 건 적중은 의미가 없고, 같은 글에서 여러 항목이 몰릴 때만 손댄다.

## 1단계가 하는 일과 하지 않는 일

| 할 수 있다 | 할 수 없다 |
|---|---|
| 문장/문단 **삭제** (채움말, 반복 요약) | 원문에 없는 사실/수치/주장/인용 **추가** |
| 문장/문단 **이동** (결론을 앞으로, 질문 순서 바꾸기) | 필자의 입장을 대신 정하기 |
| 문단 **병합/분할** | 문장 안 표현 다듬기 (2단계 몫) |
| 빠진 것을 **질문**으로 되묻기 | 질문 없이 빈칸을 그럴듯하게 채우기 |

입장(S-3)과 구체성(S-4)은 원문에 재료가 없으면 고칠 수 없다. 그때는 수정하지 않고 사용자에게 묻는다. 답이 오면 그 답만 반영한다.

## 점검표

한 번에 하나씩 본다(여러 개를 한꺼번에 보면 놓친다: sepia 실측).

| ID | 항목 | 찾는 것 | 조치 |
|---|---|---|---|
| S-1 | 정보 밀도 | 어느 맥락에나 참인 문장("빠르게 변하는 환경에서", "중요한 점은"), 절반 길이로 같은 말을 할 수 있는 문단 | 삭제. 단, 필요한 단서나 다음 행동까지 지우면 실패 |
| S-2 | 독자 과업 관련성 | 독자가 이미 아는 배경, 질문을 되풀이하는 도입, 범위 소개 투어 | 삭제 또는 한 문장으로 병합 |
| S-3 | 입장 | 판단이 필요한 글인데 결론이 없다. 비교만 하고 추천이 없다. 회고인데 인정한 실수가 없다 | **질문**. "이 글의 결론은 무엇인가요?" |
| S-4 | 구체성 | 버전, 수치, 파일 경로, 명령, 오류 원문, 이름이 있어야 할 자리가 비었다 | **질문** 또는 `TODO:` 표시. 지어내지 않는다 |
| S-5 | 프랙털 요약 | 예고 → 본문 → 재요약이 문서와 절마다 반복된다 | 예고나 재요약 중 하나를 삭제 |
| S-6 | 결론 잔여물 | "정리하면", "결론적으로"로 시작해 앞 내용을 되풀이하는 마지막 문단, 막연한 향후 전망 | 문단 삭제. 내용이 끝나는 곳에서 끝낸다 |
| S-7 | 질문 순서 (QUD) | 문단마다 답하는 질문을 하나씩 적었을 때 무엇이 → 왜 → 결과 → 의미 순의 행정 면담처럼 이어지거나, 마지막이 "이게 무슨 의미인가" 성찰로 끝난다 | 이동. 적어도 한 질문이 배경보다 먼저 오게 한다. 성찰 꼬리는 삭제 |
| S-8 | 개요 테스트 | 문단 첫 문장만 뽑아 읽으면 깔끔한 요약이 된다 | 이동/병합으로 일부 문단의 시작을 바꾼다 (첫 문장 표현 공식 자체는 C-4, 2단계 몫) |
| S-9 | 중간의 늘어짐 | 도입과 끝은 단단한데 가운데 1/3이 같은 밀도로 평평하다. 비교하거나 반박하는 문단이 하나도 없다 | 가운데에서 S-1 삭제를 먼저. 원문에 반대 사례나 예외가 있으면 그 문단을 가운데로 이동 |
| S-10 | 도입 | 업무 문서인데 배경/맥락 설명으로 연다. 답이 셋째 문단에 있다 | 답을 첫 문장으로 이동 (보고/답변 장르만. 칼럼/에세이는 제외) |
| S-11 | 강조 분포 | 모든 문단에 같은 무게의 강조가 고르게 있다 | 진단만. 어디가 핵심인지 사용자에게 묻는다 |

## 2단계로 넘기는 것 (중복 금지)

아래는 humanize-korean 분류 체계가 이미 문장 단위로 다룬다. 1단계에서 손대지 않는다.

| sepia 항목 | humanize-korean ID |
|---|---|
| 챗봇 말투 잔재 ("좋은 질문입니다", "도움이 되길") | D-1, D-3, D-4 |
| 헤지 남발 | G-1, G-2, G-3, A-10 |
| 서식 티 (볼드 소제목 불릿, 이모지, 셋 나열) | C-1, C-2, C-3, C-5, C-6, J-1 |
| 문장 틀 재활용 | C-7, C-8 |
| 결말 공식 문장 ("~할 때입니다", "향후") | D-6, D-11, D-12 |
| 문장/문단 리듬 균일 | E-1, E-2, E-3, E-4 |
| 첫 문장 요약 공식 | C-4 |

## 화이트리스트 (관례는 AI 티가 아니다)

- 정해진 양식: 장애 보고서 템플릿, PR 템플릿, 회의록 양식, 공문 형식
- 격식 있는 자리의 격식체
- 정말로 나열할 것을 나열한 불릿과 표
- 짧고 건조한 답변. 업무 메신저에서는 짧은 게 기본이다
- 필자 본인의 확인된 습관. 일반적인 "사람다움"이 아니라 그 사람 목소리 쪽으로 고친다
